## Empty frames and nominalizations / 空框架与名词化

| Longer wording | Shorter wording | Source |
|---|---|---|
| It was observed that there was | start with the finding | Pattern in the article's results example. 文章结果例句中的框架 |
| are indicative of the fact that | use the verb for the finding | Pattern in the article's discussion example. 文章讨论例句中的框架 |
| conduct an evaluation of | evaluate | Article summary of course unit 2. 文章对课程第 2 单元的概述 |
| perform a measurement of | measure | Same. 同上 |
| achieve an improvement in | improve | Same. 同上 |
| perform an analysis of | analyze | Same pattern as unit 2 (thin verb + noun). Not a line quoted from the lecture. 与第 2 单元相同的结构（空动词 + 名词）。不是讲座原句 |
| make a comparison of | compare | Same pattern. 同一结构 |
| give a description of | describe | Same pattern. 同一结构 |

Nature's Masterclasses post uses the same verb-over-noun point with `assessment` / `assess`, `estimation` / `estimate`, `correlation` / `correlate`, and `confirmation` / `confirm`. Those pairs are on that page. They are not copied here as a second table.

Nature Masterclasses 用 `assessment` / `assess`、`estimation` / `estimate`、`correlation` / `correlate`、`confirmation` / `confirm` 说明同一点。这些对子在该页上，这里不再做成第二张表。
